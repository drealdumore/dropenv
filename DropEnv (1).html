Technical details for auditors
Sender browser
 1. AES-256-GCM key via crypto.subtle (96-bit IV)     link mode: random key
 2. Encrypt .env -> ciphertext                        phrase mode: PBKDF2-SHA256 (200k) from 12 words
 3. Key stays in URL fragment (#key=...) never sent   password: second PBKDF2 layer, sealed over the first
        | ciphertext + IV + salt only
Relay (self-hosted server, shared db or local fallback)  -- holds ciphertext, 0 keys
        | recipient opens link
Recipient browser: reads #key locally -> decrypts in memory -> relay erases blob -> HTTP 410 GONE

Relay: the page uses your self-hosted server (node server.js) when it is served by it, otherwise the shared artifact database, otherwise this browser's storage. The header chip shows which one is active.
